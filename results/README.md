# Results

This directory contains the numerical outputs generated by the machine-learning experiments.

## Result files

| File | Description |
| --- | --- |
| `missing_data_accuracy.csv` | Accuracy under different missing-data levels |
| `missing_data_f1.csv` | F1-score under different missing-data levels |
| `label_noise_accuracy.csv` | Accuracy under different label-noise levels |
| `label_noise_f1.csv` | F1-score under different label-noise levels |
| `feature_selection_accuracy.csv` | Accuracy under different feature configurations |
| `feature_selection_f1.csv` | F1-score under different feature configurations |
| `overall_accuracy.csv` | Overall accuracy comparison between experiment families |
| `overall_f1.csv` | Overall F1-score comparison between experiment families |

## Models

The result tables contain values for:

- Logistic Regression;
- Decision Tree;
- Random Forest.

## Experiment conditions

### Missing data

- 0%
- 10%
- 20%
- 30%

### Label noise

- 0%
- 10%
- 20%
- 30%

### Feature selection

- Basic Features;
- Extended Features;
- All Features.

## Metrics

The project currently reports:

- Accuracy;
- F1-score.

All values in this directory are generated from the project notebooks.
